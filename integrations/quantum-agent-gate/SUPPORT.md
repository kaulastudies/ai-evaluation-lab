# Support and maintenance

Quantum Agent Gate is experimental research software, maintained on a best-effort basis by AI Evaluation Lab. There is no uptime, issue response, or bug-fix SLA.

- Report defects in kaulastudies/ai-evaluation-lab GitHub issues with prefix [QAG]. Include Python, Qiskit version, minimal circuit, logs, and expected behavior; never include credentials.
- Submit changes as small tested pull requests with positive and negative controls.
- This project follows the Qiskit Code of Conduct: https://github.com/Qiskit/ecosystem/blob/main/CODE_OF_CONDUCT.md.
- Support goal: Python 3.10+ and stable Qiskit SDK 2.x, including V2 StatevectorSampler as exercised by CI.
- Breaking changes may occur while experimental. There is no QPU support, no certified model-safety guarantee, and no IBM/Qiskit endorsement.

For sensitive security reports, use GitHub private vulnerability reporting if available or contact the maintainer privately, rather than disclosing secrets in a public issue.
