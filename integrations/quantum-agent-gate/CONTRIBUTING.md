# Contributing

Open a focused issue or pull request in kaulastudies/ai-evaluation-lab with prefix [QAG]. Add reproducible tests for positive and negative cases and run the Qiskit 2.x CI workflow. Keep real QPU, cloud API, hardware credentials and remote execution out of the prototype. Follow the Qiskit Code of Conduct at https://github.com/Qiskit/ecosystem/blob/main/CODE_OF_CONDUCT.md.
