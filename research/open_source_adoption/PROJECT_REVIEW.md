Reviewed 2026-10-29. This covers **all 125 entries supplied**, not all 2,230 marketplace listings. Titles and vendor labels identify the user's supplied catalogue; they do not establish ownership or reuse rights.

Every listed asset remains **not cleared for source reuse**. Public references below are independently verified alternatives. None grants access to a vendor's private history, tasks, data, assets or benchmark answers. A missing exact match is a search limitation, not proof that a project is closed source. The complete queries and identity notes are in [catalogue.json](catalogue.json).

P1 = near-term experimental fit; P2 = later bounded task or supporting workflow; P3 = defer. Priorities are the Lab's assessment, not claims made by the vendors. Only the Inspect JSON adapter is implemented in this branch. All other items remain proposals.
