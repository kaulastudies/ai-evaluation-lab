# Proposed supervised pilot

This is a proposal for discussion. No Army/AWPO pilot, data access, funding or deployment has been agreed.

## First discussion

Ask the referring officer or partner incubator to confirm whether PDS 6 is still an active need and identify its current user owner. Demonstrate the prototype with the bundled sample people and vacancies. Request technical review and, if appropriate, a small supervised trial with the responsible placement team.

The initial ask is a review and access discussion. A formal Open Challenge application is a separate step after confirming intake, individual-applicant conditions, product scope and matching-contribution feasibility.

## Suggested stages

| Stage | Work | Reviewable output |
| --- | --- | --- |
| 1. Define and agree | Counsellor workflow, vacancy fields, consent, retention, acceptable CV format and eligibility rules | Approved test protocol, minimal data schema, written source-access conditions |
| 2. Integrate | One authorised vacancy feed/export and one minimal candidate export; no operational or unnecessary service data | Adapter and replayable, anonymised examples |
| 3. Evaluate | Placement staff assess relevance and inspect every draft claim on a held-out set | Labelled results, error analysis, latency/cost notes and supported scope |
| 4. Decide | Review user experience, exceptions, operating cost and security requirements | Continue, revise or stop decision; separate deployment scope if justified |

An indicative first trial could use 20 consented profiles and 100 authorised vacancy records. The responsible user must approve the sample and criteria. No delivery date is committed without access and scope agreement.

## Proposed acceptance criteria — not achieved results

- Every displayed opportunity has a source URL, observation timestamp and visible deadline state. No known expired/withdrawn listing appears as current.
- Every unsupported, ambiguous or conflicting eligibility requirement remains visible for human review. No qualification or licence is inferred from a service rank.
- Every factual CV line maps to a supplied candidate fact, with no added qualification, duration, achievement or employment history.
- Placement staff judge at least one of the first five results relevant for a predefined share of held-out candidates. The threshold is agreed before evaluation, rather than selected after seeing results.
- Counsellors record review/edit time against their current process. Report paired observations, errors and exclusions; do not claim an improvement from synthetic tests.
- Evaluate the optional local selector against the deterministic baseline using the same held-out records. Invalid model output is a failure and never silently repaired into a reported success.
- Include candidates with different education levels, service categories, trades and language preferences, where consent permits. Document small-sample uncertainty and cases needing accommodation.

## Data and deployment decisions

The current demonstration requires no user database. An institutional pilot needs an agreed consent process, minimal personal fields, access controls, retention/deletion rules and named reviewers. Do not collect service numbers, operational histories, medical records, identity-document scans or other unnecessary information for this employment prototype.

If a funded product proposal follows, budget source integration, counsellor time, model evaluation, accessibility, authentication, hosting, maintenance and independent verification explicitly. SPARK funding rules and matching contribution must be agreed with DIO/the incubator; this document is not a funding award or a cost quotation.
