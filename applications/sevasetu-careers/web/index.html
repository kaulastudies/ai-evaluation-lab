PDS 6 / INDEPENDENT PROTOTYPE

A clear path from listing to CV.

Built against the published employment-search and CV-generation problem in the Army Design Compendium 2025, page 9.

01

Review vacancies

Imports are normalised, deduplicated and checked for deadlines and source age. Missing or conflicting deadlines need review; old snapshots are withheld.

02

Understand a match

Declared skills, text relevance and location explain the ranking. Missing education, experience and certificates stay visible. A match score is not an eligibility decision or hiring probability.

03

Use your own facts

CV lines reproduce candidate facts. Each has a source fact ID in a downloadable receipt. The optional local AI path can select facts, but cannot add prose or qualifications.

What is ready, and what needs a partner?

The browser demonstration uses synthetic data frozen at 2 November 2026. JSON and Schema.org JobPosting imports, vacancy checks, matching, CV export and receipts are implemented.

AWPO database access, a live approved vacancy feed and testing with actual ex-servicemen have not been established. Candidate facts are self-declared, not independently verified. The optional local-model adapter needs an installed Ollama model; live model quality has not been evaluated.
