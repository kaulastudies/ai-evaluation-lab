WHAT MAKES THIS TEST USEFUL

A denial is only half the answer.

The paired continuation case checks that an unrelated revocation preserves the same queued action and its existing grant. A global shutdown fails this test, even if it blocks every unauthorized write.

WHERE THE CLAIM STOPS

One local transaction domain.

Authority, effects, and events share a SQLite transaction. The browser does not test remote services, distributed caches, process crashes, or concurrent workers. The repository’s separate native suite covers bounded concurrency and lock contention. A valid local hash chain is not external attestation.
