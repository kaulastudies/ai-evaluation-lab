# AI Evaluation Lab — One Page

## The evidence layer for AI systems and agents

AI Evaluation Lab is an independent emerging lab building reproducible evaluation infrastructure for models and agents.

### Problem

AI teams can generate outputs and traces easily. They have a harder problem proving that a model or agent behaved correctly, consistently, and reproducibly across versions.

### Product thesis

Turn evaluation into an operating system:

**Task → Run → Evidence → Verification → Review → Adjudication → Evaluation Record → Regression → Release Evidence**

### Working today

- versioned evaluation records;
- deterministic verification;
- disagreement/adjudication model;
- regression linkage;
- Harbor-compatible task runtime;
- independent verifier;
- negative/positive controls;
- local Docker + Harbor execution;
- Ollama + Inspect AI baseline;
- canonical record hashing;
- CI-gated public evidence.
