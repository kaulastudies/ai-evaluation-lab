# Public Evaluation References

These systems inform interoperability and architecture only. Their tasks and code remain subject to their own licenses and restrictions.

- Harbor / Terminal-Bench — isolated task environments, reference solutions, separate verifiers, outcome-based rewards
- UK AISI Inspect — provider-neutral evaluation execution, agents/tools, sandboxes, structured logs
- METR task standards — interoperable task/environment concepts
- SWE-bench — repository state, patches, containers, objective verification
- Langfuse — datasets, experiments, annotation and evaluation observability
- DeepEval — application-level evaluation and CI
- Promptfoo — testing and security/red-team evaluation

Original Lab tasks should be independently authored from public, synthetic, or explicitly authorized material.
