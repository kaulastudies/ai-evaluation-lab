## What helps ProofPay now

The fixed-sample PayPal sandbox diagnostic already proves its recorded capture/recovery path. The remaining resource need is a real, bounded model call that proposes a catalogue SKU and rationale. The server must continue to own price, merchant, allowance, approval and payment execution.

The rules allow any meaningful AI integration alongside central PayPal sandbox use; sponsors are optional. The five equally weighted criteria are Technological Implementation, Design, Potential Impact, Innovation/Idea and Presentation. Completing the actual model-to-payment journey is more useful against those criteria than adding several unrelated sponsor tools. A sponsor prize requires the corresponding tool's actual qualifying use, not its name in the pitch. [Rules §§4, 6, 8](https://paypalaihackathon.devpost.com/rules)

## Runtime AI: selected route and alternatives

### Astropods alternative — not activated

Check the actual signup grant, remaining balance, expiry and no-card state. The official [gateway guide](https://docs.astropods.com/ai-gateway) describes account-scoped credentials injected into Astropods agent containers. The [chat API](https://docs.astropods.com/ai-gateway/chat) supports OpenAI-compatible chat completions and structured output under `${ASTRO_GATEWAY_URL}/v1`; [supported model IDs](https://docs.astropods.com/ai-gateway/models) include small classification-oriented choices.

That request format fits ProofPay's existing proposal adapter in principle. Verify supported access from the actual deployment before configuring it; the docs do not establish unrestricted reuse of injected container credentials elsewhere. If a small Astropods proposal service is needed, keep it responsible only for a SKU/rationale. Keep the durable purchase service, merchant secrets and approval rules in ProofPay. Do not move the financial ledger to obtain trial credits.

Use gateway-managed models. Do not add an OpenAI provider-key configuration or a fallback to the owner's personal provider account. Record the actual model response and budget usage after a bounded test; an account signup or installed SDK alone does not close the AI gate.

### Vercel free AI Gateway — selected implementation

Vercel is not one of the ten listed sponsors. Its current [pricing](https://vercel.com/docs/ai-gateway/pricing) offers **$5/month to the free tier**, starting with the first request. Only [free-tier eligible models](https://vercel.com/ai-gateway/models?freeTier=true) are covered, with lower limits. Purchasing credits changes the team to paid and removes the monthly free grant; BYOK is paid-tier functionality. Verify the selected team's actual state, available grant and disabled automatic top-up before using it.

The [compatible endpoint](https://vercel.com/docs/ai-gateway/sdks-and-apis/openai-chat-completions) is `https://ai-gateway.vercel.sh/v1`. The current implementation uses Vercel OIDC at runtime, pins `openai/gpt-4.1-mini`, and rejects legacy personal/API-key variables. Verify free-tier eligibility and JSON response support before the bounded call. The model name does not mean a personal OpenAI account is being used. Do not attach BYOK credentials or purchase credits to work around a restriction.

The owner's selected deployment is GitHub plus native Next.js on Vercel with Neon/Postgres, replacing the earlier Sites/Worker runtime. Model access remains separate from payment authority. `AI_FUNDING_MODE=vercel-free-credit`, a declared checked grant/expiry, `AI_GATEWAY_MAX_REQUESTS=1` and the fixed model constrain the proposed run. Runtime OIDC supplies credentials; do not paste tokens into source or configuration. A durable attempt is consumed before dispatch, including failures; there is no automatic retry or alternate provider. These controls bound requests rather than independently certifying billing.

### Elastic only if needed

[Managed LLMs](https://www.elastic.co/docs/explore-analyze/ai-features/llm-guides/llm-connectors) are available without a separate provider key on qualifying deployments, but are metered. The [trial documentation](https://www.elastic.co/docs/get-started/evaluate-elastic) imposes token limits. Confirm the trial's usable model allowance and expiry before choosing this heavier route. Running Elasticsearch locally does not itself provide free LLM inference.

**Do not plan around GitHub Models:** [GitHub's current documentation](https://docs.github.com/en/github-models) says the service, including inference API and BYOK, was retired on **30 July 2026**. GitHub Copilot is separate; coding assistance is not the runtime proposal call.
