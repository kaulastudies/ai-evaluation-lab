01 / The approach

Make the verdict
worth trusting.

We start with a bounded task, test the verifier itself, and retain the evidence behind the result.

01 — DEFINE

Write the contract.

Make success and failure explicit before the run. Specify the inputs, constraints and behaviour the task actually requires.

02 — CHALLENGE

Check the checker.

Use reference implementations, known-bad candidates and deliberate mutations to test whether a verifier catches the faults it should.

03 — REPRODUCE

Keep the evidence.

Retain the code, failed checks, source references and execution reports. Make the result available for inspection and replay.

02 / Research programs

Specific questions.
Reproducible work.

The Lab develops open task contracts, verifiers and evaluation records around concrete agent behaviours.

RARB

Repository Agent
Reliability

Evaluate coding agents against explicit repository tasks. Examine false passes, bounded repairs and whether a result can be replayed.

↗
SAFETY

Agent Safety
Evaluation

Study permission boundaries, constraint adherence and regressions through bounded tasks with explicit criteria and limitations.

↗

Results apply to the tasks and conditions tested. They are not a general safety certification or a guarantee of production reliability.
